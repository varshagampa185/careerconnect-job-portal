# CareerConnect – Job and Internship Portal

CareerConnect is a responsive job and internship tracking web application built using HTML, CSS, and JavaScript.

## Features

* Search opportunities by keyword.
* Filter by job category and employment type.
* Save and remove favorite jobs.
* Track job applications and interview statuses.
* Add and delete custom job listings.
* View dashboard statistics.
* Save application data in browser Local Storage.
* Responsive layout for desktop and mobile.

## Technologies

* HTML5
* CSS3
* JavaScript
* Local Storage API

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.

No backend server or database is required for this demonstration version.

## Limitations

This project uses browser Local Storage. Data is specific to the browser and device where it was saved. Job listings are demonstration data and are not live vacancies.
